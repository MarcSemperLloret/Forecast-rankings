# Public package allowlist

Only the following classes are authorized for the eventual public repository:

- `src/`, `scripts/` and `config/`;
- selected aggregate `results/` tables, summaries, figures, alt text and manifests;
- `README.md`, `REPRODUCIBILITY.md`, `DATA_AVAILABILITY.md`, `LICENSE`,
  `CITATION.cff`, `pyproject.toml`, `.gitignore` and `CHECKSUMS.sha256`.

The manuscript, supplement, cover letter, title page, editorial simulations,
claim matrices, internal gates, reviewer materials, raw observations, provider
archives, credentials and personal upload metadata are prohibited.
