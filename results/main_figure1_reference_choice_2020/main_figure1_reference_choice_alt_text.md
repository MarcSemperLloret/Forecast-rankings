Three-panel figure. Panel a contrasts a station sampling a local environment with an area-supported grid-box state at the same nominal location. Panel b shows mean absolute error and 95% temporal bootstrap intervals for GraphCast, IFS and Pangu against AVAMET stations and ERA5. GraphCast has the lowest station error, while Pangu has the lowest ERA5 error. Panel c shows the GraphCast-minus-Pangu contrast: negative against stations, positive against ERA5, and a negative paired reference effect whose interval excludes zero.
